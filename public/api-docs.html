Antigravity Resets API

← Back to tracker

Free keyless JSON, RSS, and SVG badge endpoints for scripts, menu bars, and AI agents checking official Google Antigravity quota resets.

GET /api/v1/status

Returns the latest regular or banked reset, interval statistics, thanks count, and live presence count. 

curl -s https://antigravity-resets.com/api/v1/status | jq
GET /api/v1/resets

Returns the chronological reset archive. Optional query parameters: type=regular|banked and limit=1..200. 

curl -s "https://antigravity-resets.com/api/v1/resets?type=regular&limit=5" | jq
GET /feed.xml /api/v1/badge.svg

Subscribe in any RSS reader via /feed.xml, or embed a live status badge in your README using /api/v1/badge.svg. 

![Antigravity Reset](https://antigravity-resets.com/api/v1/badge.svg)
GET / POST /api/webhooks/x

Verified X Activity (post.create) and legacy webhook receiver with HMAC-SHA256 CRC validation and raw-byte verification. Replied-to parent posts and quoted posts are resolved separately from data.includes (and missing parents can be auto-hydrated via X API v2 when X_BEARER_TOKEN is configured). Candidate posts are jointly judged in parallel by Google Gemini Decisions API (gemini-decision-1) and Google Gemini 3.8 Flash (gemini-3.8-flash). Both Tier-1 judges must concur on reset status and type (regular vs banked) to auto-publish; disagreements escalate to a Tier-2 frontier arbitrator (gemini-4-neon), and any remaining uncertain or missing-context events enter /api/v1/admin/review with optional private admin Telegram alerts (never public broadcast). 

# CRC challenge check
GET /api/webhooks/x?crc_token=<token>

# Event delivery headers
X-Twitter-Webhooks-Signature-OAuth2: sha256=<base64-hmac>
GET / POST /api/v1/admin/review /api/v1/admin/review/resolve

Bearer-authenticated operator queue for inspecting and approving or dismissing held needs_review webhook events. 

curl -s -H "Authorization: Bearer $ADMIN_API_TOKEN" \
  https://antigravity-resets.com/api/v1/admin/review | jq
