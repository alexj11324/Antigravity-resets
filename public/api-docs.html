Antigravity Resets API

← Back to tracker

Free keyless JSON, RSS, and SVG badge endpoints for scripts, menu bars, and AI agents checking official Google Antigravity quota resets. Read how quota and resets work first if the terms below are unfamiliar.

Quick start

Base URL https://antigravity-resets.com. There is no authentication, no API key, and no account. Reads are cached at the edge, so a polling script costs nothing. 

curl -s https://antigravity-resets.com/api/v1/status | jq

Every read endpoint is CORS-open (Access-Control-Allow-Origin: *) and returns UTF-8 JSON. Unknown paths and unsupported methods return 404 with {"error":"Not found"}.

GET /api/v1/status

The current answer to "did Antigravity reset today?" — the latest verified reset, the aggregate statistics behind the tracker, and the live viewer count.

Top-level fields

GET /api/v1/resets

The complete archive, newest first. Every reset this tracker has verified, with the original text, translations, and source link.

Query parameters

ParameterTypeMeaning
typeregular | bankedFilter by reset type. Omit for both.
limitinteger 1–200Return only the newest N resets. Invalid values are ignored rather than rejected.

limit pages the response; it does not change stats, which always describe the full archive that matched type. count is the number of items in this response. 

curl -s "https://antigravity-resets.com/api/v1/resets?type=regular&limit=5" | jq '.resets[].timestamp'

GET /feed.xml /rss.xml /api/v1/badge.svg

/feed.xml is an RSS 2.0 feed of verified announcements, refreshed within a minute of a new reset. /rss.xml is an alias. /api/v1/badge.svg is a live status badge sized for a README or a menu bar; it renders the current state without JavaScript.

POST /mcp

Remote Model Context Protocol server over Streamable HTTP (JSON-RPC 2.0), so an AI agent can ask the tracker directly instead of scraping the page. No authentication and no key.

Tools

ToolArgumentsReturns
get_status none Latest reset, any announced-but-pending reset, and aggregate statistics.
list_resets type, from, to, order, limit (1–100), cursor A page of the archive plus an opaque nextCursor for the following page.

Both tools are annotated read-only. A failed tool call returns a JSON-RPC error with a fixed message; internal detail is never echoed to the client. 

claude mcp add --transport http antigravity-resets https://antigravity-resets.com/mcp
{
  "mcpServers": {
    "antigravity-resets": {
      "type": "http",
      "url": "https://antigravity-resets.com/mcp"
    }
  }
}

Errors, caching, and limits

StatusBodyWhen
200JSONNormal read.
304emptyIf-None-Match matched the current ETag. Cache headers are preserved.
404{"error":"Not found"}Unknown path, or a method the path does not implement.
429{"error":"Too many requests"}Flood guard tripped. Wait ten seconds and retry.

Caching

/api/v1/status is cached for 15 seconds at the edge, /api/v1/resets, the badge, and the feeds for 60 seconds. Every response carries an ETag; send it back as If-None-Match and a poll that changes nothing costs one 304.

Rate limits

Read endpoints are served from the edge cache and are not rate limited. The /mcp endpoint allows 30 requests per 10 seconds per IP per Cloudflare location; above that it returns 429 for ten seconds. The site's own write endpoints (subscriptions, reactions) share the same flood guard.
